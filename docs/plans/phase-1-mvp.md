# Phase 1 — 핵심 MVP

세로 슬라이스 순서(roadmap.md)로 진행. 태스크 상세는 착수 직전에 구체화하고 여기 갱신한다.

## 슬라이스 A — 텍스트 핵심 루프
| ID | 태스크 | 완료 기준 |
|---|---|---|
| P1-A1 | 앱 셸: go_router, 테마, l10n(ko/en), 온보딩 미완료 redirect | 위젯 테스트로 redirect 검증 |
| P1-A2 | S02 API 설정: 공급자 선택, 키 입력(마스킹), 연결 테스트, 모델 선택, 키 교체/삭제 | 오류 4종(키/잔액/한도/네트워크) 메시지 위젯 테스트 |
| P1-A3 | PromptComposer + 마스터 프롬프트(packages/prompt_assets, 버전 태그) | 계층 순서·변수 치환·인젝션 방어 단위 테스트 |
| P1-A4 | ConversationPolicyEngine: Daily 모드, 힌트 4단계, 교정 타이밍 | 정책 단위 테스트 |
| P1-A5 | S06 텍스트 대화 화면: 스트리밍 응답, 힌트/천천히/종료, 점수 비노출 | 위젯 테스트 + 수동 시나리오 |
| P1-A6 | FeedbackService: JSON 스키마 검증, turn ID 연결, 1회 재요청 폴백 | 잘못된 JSON·없는 원문 거부 테스트 |
| P1-A7 | S07/S08 교정·결과 화면, 세션 저장/중단/복구 | 강제 종료 후 복구 통합 테스트 |

**Phase 1 종료 기준:** 30분 세션 시작 → 종료 → 피드백 → 복습을 macOS·Windows에서 오류 없이 수행, Galaxy는 APK로 확인 (spec §15, ADR-009). iOS는 ADR-012로 설치본 확인 추가. 확인 항목: `docs/qa/phase-1-checklist.md`.
