# Phase 1 기기 확인 체크리스트

Phase 1 종료 전에 사람이 실제 기기에서 확인할 항목. 자동 테스트로 대신할 수 없는 것만 모았다(마이크·음성 인식·OS 동작·설치).
결과는 `docs/plans/PROGRESS.md`에 날짜와 함께 기록한다.

## 기기별 필수 흐름

## 같이 봐 둘 것 (spec §16.3)
- 블루투스 이어폰 연결/해제, 스피커로 들을 때 AI 목소리를 내 말로 잘못 인식하는지
- 음성 인식 정확도: 자주 틀리는 단어 예시 메모 (P1-B1a 맥락 힌트 효과)
- 한국어·영어 섞어 말하기, 20초 이상 침묵 → 힌트 제안
- ChatGPT 사용 한도 도달 시 안내 문구

## 플랫폼별 메모
- **macOS:** 서명 없는 빌드 → 처음 한 번 우클릭 → 열기. 키체인 창이 뜨면 직접 암호 입력 + "항상 허용".
- **Windows:** SmartScreen "추가 정보 → 실행". 음성 인식은 Windows 음성 기능(베타 패키지)이라 가장 불안정할 수 있음.
- **Galaxy:** APK 설치 시 "알 수 없는 앱 설치" 허용. 로그인 후 브라우저에서 "앱으로 돌아가기".
- **iPhone:** 서명 필요(ADR-012). 개발자 모드 + VPN 및 기기 관리에서 신뢰. 무료 Apple ID는 7일마다 재설치.
