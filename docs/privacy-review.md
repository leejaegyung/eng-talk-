# 개인정보 검수 (Phase 3)

spec §13, §16.2. 출시 전 이 표가 실제 코드와 맞는지 다시 확인한다. 바뀌면 이 문서와 온보딩 데이터 안내(`features/common/privacy_notice.dart`)를 함께 고친다.

마지막 검수: 2026-10-18 (v0.5.0 이후 코드 기준)

## 데이터 목록
| 데이터 | 어디에 | 기기 밖으로 | 보관·삭제 |
|---|---|---|---|
| 대화 글자(내 말·AI 답) | 로컬 SQLite (`sessions`, `turns`) | 고른 AI로 전송: ChatGPT 구독(OpenAI), Gemini 무료 키(Google) | 설정 → 전체 삭제, 기록 화면에서 개별 삭제 |
| 피드백·교정·표현·복습 | 로컬 SQLite | 피드백 생성 시 대화 글자를 고른 AI로 전송 | 대화와 함께 삭제(cascade) |
| 레벨 진단 답변·결과 | 로컬 SQLite (`assessments`) | 채점 시 답변 글자를 고른 AI로 전송 | 전체 삭제에 포함 |
| 음성(마이크 소리) | 저장 안 함 | OS 음성 인식(Apple·Google·Microsoft 서버에서 처리될 수 있음) | 원본 없음 |
| 말한 시간·소리 크기 | 턴별 ms만 저장(레벨 원값은 저장 안 함) | 없음 | 대화와 함께 삭제 |
| ChatGPT 로그인 토큰, Gemini 키 | OS 보안 저장소(CredentialVault)만 | 해당 공급자에게만, 요청 헤더로 | 로그아웃/키 삭제 시 제거. 전체 삭제는 유지(로그인 유지가 의도) |
| 설정(목표·레벨·음성 옵션) | 로컬 SQLite (`app_settings`) | 없음 | 앱 삭제 시 |
| 오류 기록 | 앱 지원 폴더 `errors.jsonl`(최대 100건) | 없음(사용자가 내보낼 때만) | 설정 → 오류 기록 지우기 |

## 확인 항목
| # | 항목 | 상태 | 근거 |
|---|---|---|---|
| 1 | 키·토큰이 DB·로그·내보내기에 없음 | ✅ | arch_lint 키 컬럼 금지, `AppLogger.redact`(sk-, AIza, Bearer, JWT), 내보내기 자격증명 미포함 테스트 |
| 2 | 로그에 대화 내용 없음 | ✅ | arch_lint 규칙: 로그 문자열에 text/transcript/heard/answer/key/token 등 보간 금지(spec §16.2 자동 검사) |
| 3 | 오류 기록에 대화 내용 없음 | ✅ | `errorEntryFor`: 오류 종류 + 200자 이하 마스킹 메시지 + 앱 코드 위치만. 진단 내보내기 테스트에서 대화 미포함 확인 |
| 4 | 녹음 원본 미저장 | ✅ | OS 인식기는 결과 글자만 반환. 오디오 실험실의 임시 WAV는 재생 후 삭제 |
| 5 | 무료 Gemini 데이터 사용 고지 | ✅ | 설정에서 Gemini 선택 시 안내 + 온보딩 데이터 안내 문구 |
| 6 | 서버로 보내는 오류 리포팅 없음 | ✅ | 의도적으로 로컬 전용. 외부 크래시 수집(Sentry 등)을 넣으려면 ADR과 동의 화면 필요 |
| 7 | 키를 URL에 넣지 않음 | ✅ | Gemini는 `x-goog-api-key` 헤더, 테스트로 URL에 키 없음 확인 |
| 8 | 내보내기·복원·전체 삭제 | ✅ | 설정 → JSON/CSV 내보내기(백업 v2, 학습 설정만 포함·키 없음), 백업 복원(병합), 전체 삭제(위젯·왕복 테스트). macOS 실제 파일 쓰기 integration_test |
