# Speaking Coach — AI 영어 말하기 코치

AI와 영어로 대화하며 **말하기**를 연습하는 앱입니다. AI는 짧게 묻고, 여러분이 길게 말합니다. 대화가 끝나면 고칠 문장·어순·표현을 정리해 주고, 반복 복습으로 입에 붙게 도와줍니다.

- **추가 요금 없음:** ChatGPT Plus/Pro 구독으로 로그인해서 씁니다. Gemini 무료 키도 선택할 수 있습니다.
- **기록은 내 기기에만:** 서버가 없습니다. 대화 기록·복습은 각자의 기기(또는 브라우저)에만 저장됩니다.
- **지원 기기:** 갤럭시(Android) · Windows · Mac · 아이폰/아이패드(웹 앱)

## 1. 설치

최신 버전은 **[Releases](https://github.com/leejaegyung/eng-talk-/releases/latest)** 에서 받습니다.

| 기기 | 받을 것 | 설치 방법 |
|---|---|---|
| **아이폰·아이패드** | 웹 앱: **https://leejaegyung.github.io/eng-talk-/** | **Safari**로 열기 → 공유 버튼 → **홈 화면에 추가** → 홈 화면 아이콘으로 실행. 설치·서명 필요 없음 |

| **Windows** | `SpeakingCoach-*-windows-x64.zip` | 압축 해제 → `speaking_coach.exe` 실행. SmartScreen 경고가 뜨면 "추가 정보 → 실행" |

## 2. 처음 실행할 때 (약 3분)

앱을 처음 열면 안내가 차례로 나옵니다.

1. **언어** — 기기 설정 / 한국어 / English
2. **데이터 처리 안내** — 무엇이 어디로 가는지 확인 → "확인했어요"
3. **학습 목표** — 일상 대화·여행·업무·면접·자신감 중 하나, 하루 목표 시간(10~45분). 건너뛰어도 되고 나중에 설정에서 바꿀 수 있어요
4. **AI 연결 — ChatGPT로 로그인**
   - **앱(갤럭시·Windows·Mac):** 브라우저가 열리면 ChatGPT에 로그인하고 허용 → 앱으로 돌아오면 끝.
   - **웹(아이폰·아이패드):** 새 탭에서 로그인하고 나면 **"사이트에 연결할 수 없음"** 페이지가 뜹니다. 정상이에요. 그 페이지 **주소창의 주소 전체**(`http://127.0.0.1:1455/auth/callback?code=…`)를 복사해서 앱의 입력칸에 붙여넣으세요.
   - ChatGPT **Plus 또는 Pro** 구독이 필요합니다. 구독 사용 한도 안에서 동작하고 추가 요금은 없습니다.
5. 홈 화면에서 **레벨 진단**(질문 5개, 약 5분)을 해 두면 내 수준에 맞게 대화합니다.
6. 마이크 권한을 물으면 **허용**해 주세요.

## 3. 추천 설정 (설정 ⚙️)

| 설정 | 추천 | 설명 |
|---|---|---|
| **음성 인식** | **Gemini (정확)** | 기기 내장 인식은 이름·억양에 약해요(예: "Oasis music" → "watch this music"). Gemini는 말을 마친 뒤 녹음을 받아써서 훨씬 정확합니다. 무료 키가 필요해요(아래) |
| **자동 듣기 (핸즈프리)** | 켜기 | AI가 말을 마치면 🎤를 누르지 않아도 바로 들어요 |
| **말하면 AI 말 끊기** | 이어폰 쓸 때만 | 스피커로 들으면 AI 목소리를 내 말로 착각할 수 있어요 |
| **말한 뒤 확인하고 보내기** | 인식이 자주 틀리면 | 인식된 문장을 고친 뒤 보낼 수 있어요 |
| **복습 반복 횟수** | 5회 또는 10회 | 문장마다 반복할 횟수(체크 박스) |

### Gemini 무료 키 받기 (선택, 음성 인식을 정확하게)
1. **https://aistudio.google.com** 접속 → Google 계정으로 로그인
2. **Get API key → Create API key** (결제 등록 필요 없음)
3. 앱 **설정 → 음성 인식 → Gemini (정확)** → 아래 칸에 키 붙여넣기 → **저장하고 확인**

- 키는 기기의 보안 저장소에만 보관됩니다. **채팅이나 다른 곳에 붙여넣지 마세요.**
- 무료 키에서는 보낸 내용(녹음 포함)이 Google 서비스 개선에 쓰일 수 있어요. 개인정보는 말하지 마세요.
- 대화 상대 AI는 ChatGPT 그대로 두고 음성 인식만 Gemini로 쓸 수 있습니다. 원하면 **대화에 쓸 AI**도 Gemini로 바꿀 수 있어요.

## 4. 이렇게 쓰세요

1. **대화 시작** → 모드(일상·테마·역할극·랜덤·이야기·의견), 레벨, 주제 선택 → 시작
   - 주제가 떠오르지 않으면 **🎲 랜덤 (AI가 정해요)**
   - 막히면 아래 버튼: **힌트 · 다시 말해줘 · 천천히 · 이 문장 교정 · 주제 변경**
2. **종료** → 결과 화면
   - **고쳐 말해볼 문장**과 **어순 체크**(내 문장마다 ✅ / 바른 어순)
   - **따라 말하기**: 코치 문장을 듣고(🔊, 🐢 천천히) 그대로 따라 말하기
3. **복습** (홈 → 복습할 문장): 교정된 문장을 소리 내어 반복 → 맞게 말하면 체크 박스가 채워져요. 1·3·7·14·30일 간격으로 다시 나옵니다
4. **성장 기록** (홈 📈): 연습 시간, 자주 고친 부분 → 누르면 **미니 설명**(내 실수 기반 규칙 + 예문 + 내 문장 연습)

## 5. 기록 옮기기·백업

서버가 없으므로 기기를 바꾸거나 앱을 다시 설치할 때는 직접 옮깁니다.

- **내보내기:** 설정 → **대화 기록 내보내기** → `speaking-coach.json` 저장
- **복원:** 새 기기/앱에서 설정 → **백업 파일에서 복원** → 그 파일 선택
- 로그인 정보와 키는 백업에 들어가지 않으니 다시 로그인해 주세요.

## 6. 문제 해결

| 증상 | 해결 |
|---|---|
| 말한 것과 다른 단어로 인식됨 | 설정 → 음성 인식 → **Gemini (정확)**. 갤럭시는 휴대폰 설정 → 일반 → 기본 음성 인식 서비스를 **Google**로 |
| 마이크가 안 됨 | 기기 설정에서 이 앱(또는 Safari)의 **마이크·음성 인식 권한** 허용. 이어폰·마이크 연결 확인 |
| 아이폰 웹 앱에서 음성 인식이 안 됨 | 홈 화면 앱 대신 Safari 탭에서 열어보기, 또는 입력해서 대화 |
| Mac에서 키체인 암호 창이 뜸 | 직접 Mac 암호 입력 → **항상 허용** |
| "ChatGPT 구독 사용 한도" 안내 | 잠시 후 다시 시도 (구독 한도는 ChatGPT 설정에서 확인) |
| 갤럭시 업데이트가 설치되지 않음 | v0.5.0 이하에서 올라올 때 한 번만: 내보내기 → 앱 삭제 → 새로 설치 → 복원 |
| 그 밖의 오류 | 설정 → **진단 정보 내보내기** 파일을 [Issues](https://github.com/leejaegyung/eng-talk-/issues)에 첨부 (대화 내용·키는 들어가지 않아요) |

## 7. 개인정보

- 대화 글자는 고른 AI(ChatGPT 또는 Gemini)로 보내져 답변·피드백을 만듭니다.
- 음성 녹음은 **저장하지 않습니다.** 기기 내장 인식 또는(선택 시) Gemini로만 보내집니다.
- 대화 기록·복습·설정은 **내 기기에만** 저장되고, 설정에서 언제든 전체 삭제할 수 있습니다.
- 자세한 내용: [`docs/privacy-review.md`](docs/privacy-review.md)
